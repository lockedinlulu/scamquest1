# ScamQuest 🛡️  
### Cybersecurity Education Game | Hack Brooklyn – Entertainment Track Winner

ScamQuest is a web-based interactive cybersecurity education game that simulates real-world phishing, scam, and social engineering attacks through scenario-based gameplay. Players must identify threats across emails, messages, calls, and files while managing limited lives (“hearts”) and making high-stakes decisions.

---

## 🧠 Overview
Built in a 2-day hackathon consisting of over 100+ participants, ScamQuest turns cybersecurity awareness into an interactive experience where users learn to recognize and respond to digital threats in realistic scenarios.

---

## ⚙️ Features
- Email, messaging, and phone call-based scam simulations  
- Scoring system and fail-state mechanics (hearts system)  
- Scenario-based decision-making gameplay  
- AI-generated scam call audio for realism  
- Real-world scam examples for learning reinforcement  

---

## 🛠️ Tech Stack
**Frontend:** HTML, CSS, JavaScript  
**Backend / Auth:** Firebase (authentication + persistent data storage)  
**APIs:**  
- Tavily (real-world scam examples)  
- ElevenLabs (AI-generated scam call audio)  

**Tools:** VS Code, Git, GitHub, Notion  
**AI Assistance:** ChatGPT, Claude (debugging, ideation, rapid prototyping)
